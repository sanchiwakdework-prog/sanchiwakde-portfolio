# Sanchi Wakde — Portfolio

A single-page professional portfolio inspired by the supplied Claude artifact screenshots.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with the real email.
2. Replace `YOUR-HANDLE` with the real LinkedIn handle.
3. Review every project description for confidentiality before publishing.
4. If you want a resume button, add the PDF as `resume.pdf` and link it from the hero/contact area.

## Deploy
The folder is static HTML/CSS/JS and can be deployed directly to GitHub Pages, Netlify, Vercel, or any static hosting provider.
